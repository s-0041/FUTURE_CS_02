# FUTURE_CS_02 – Phishing Detection & Awareness

## About the Project

This project was completed as part of the Future Interns Cyber Security Task 2.

The task focuses on phishing email analysis and security awareness. The objective is to analyze phishing email samples, identify common phishing indicators, classify email risk, explain the attack in simple language, and create awareness guidelines that help users avoid phishing attacks.

## Objectives

- Analyze a phishing email sample
- Identify phishing indicators
- Analyze email headers and authentication results
- Inspect sender information and links
- Classify the email risk
- Explain the attack in simple, non-technical language
- Create prevention and awareness guidelines

## Sample Analyzed

This project analyzes one phishing email sample impersonating Microsoft.

The original email is preserved in:

`sample/sample.eml`

A cleaned, readable representation is available in:

`sample/sample_email_readable.txt`

## Analysis Approach

The analysis focuses on:

1. Email header information
2. Sender and domain analysis
3. SPF, DKIM and DMARC authentication results
4. Suspicious links and URLs
5. Social-engineering indicators
6. Risk classification
7. User prevention and awareness recommendations

## Tools Used

- Email header analysis
- Browser tools for safe inspection of URLs and domains
- Text editor for examining the `.eml` sample
- Documentation/reporting tools
